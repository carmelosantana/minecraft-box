# The Box Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build the creature described in `docs/superpowers/specs/2026-08-17-box-design.md` — a black shulker that moves only while unobserved, feeds on the experience of whoever watches it, grows in stages, and is killable only while feeding.

**Architecture:** Correctness-critical geometry and state are pure classes (no Bukkit) built and tested directly in JUnit — `GazeMath`, `StepPlanner`, `StageTable`, `StarvationCurve`, `BoxConfig`, `BoxState`, `BoxCodec`. Thin Bukkit adapters (`GazeService`, `MovementService`, `FeedingService`, `SpawnService`, listeners) drive those pure cores against the live world and are verified at gate 7a, not in unit tests. One `BukkitTask` ticks every 2 ticks over a registry of tracked creatures.

**Tech Stack:** Java 25, Paper API 26.1.2 build 74 (provided scope), JUnit Jupiter 5.10, SnakeYAML (test only, inherited). Maven Shade bound to `package`. No external services. No runtime dependencies beyond Paper.

## Global Constraints

- Java `maven.compiler.release` 25; Paper API `26.1.2.build.74-stable` (provided); `plugin.yml` `api-version: '26.1'`. Copy these verbatim; do not bump.
- Package root `org.xpfarm.box`. Maven `org.xpfarm:box`. Built JAR `box-0.1.0.jar`. `plugin.yml` name `TheBox`. Never rename a link of this chain.
- Every source file starts with the AGPL-3.0-or-later header block already used by `BoxPlugin.java` (copy it verbatim).
- **Geyser/Floodgate parity is non-negotiable.** Use only vanilla entities, potion effects, particles, sound events, PDC, chat components, titles, and `teleport()`. No client-specific packets, no NMS, no resource-pack assumptions, no blocks-on-heads, no display entities. Every mechanic must read identically for a Floodgate Bedrock player.
- **XP is experience POINTS, not levels**, everywhere — draining, banking, artifact storage, return. Use `Player#getTotalExperience`-style point accounting via a pure helper; never `getLevel()`.
- **`spawn.enabled` defaults to `false`.** Installing/updating the plugin must be inert until an operator opts in.
- Invalid config logs the offending key and value and falls back to the default; it never fails plugin or server startup, except a wholesale unparseable file disables the plugin gracefully (matches the reference `onEnable` pattern).
- TDD: write the failing test, watch it fail, minimal implementation, watch it pass, commit. Pure-logic tasks are fully unit-tested. Adapter tasks carry a `PluginDescriptorTest`-style or logic-extracted test where possible and are otherwise marked for gate 7a runtime verification.
- Run the build with:
  ```bash
  JAVA_HOME=$HOME/.sdkman/candidates/java/current $HOME/.sdkman/candidates/maven/current/bin/mvn --batch-mode --no-transfer-progress clean verify
  ```

### Task 4: StepPlanner + Passability

**Files:**

**Interfaces:**
- Produces:
  - `interface Passability { boolean isPassable(int x, int y, int z); }` — true when a creature block can occupy that cell (air/non-solid).
  - `record Cell(int x, int y, int z)`.
  - `final class StepPlanner` with `StepPlanner(int maxStepUp, int maxStepDown, int maxClimbHeight, boolean allowCeiling)` and `Optional<Cell> next(Cell from, Cell victim, Passability world)`. Returns the single best adjacent cell one block toward `victim`, applying: ground step (flat, up to `maxStepUp`, down to `maxStepDown`), wall climb (vertical ascent up to `maxClimbHeight` when the horizontal step is blocked and a climbable face exists), ceiling traversal (when `allowCeiling`), flanking (the two cells perpendicular to the blocked axis), or `Optional.empty()` when fully blocked (the "wait" outcome). Never returns a non-passable cell. Never returns `from`.

- [ ] **Step 1: Write the failing test** — build in-memory worlds as a `Set<Cell>` of solid blocks and assert the chosen next cell.

```java
package org.xpfarm.box.model;

import static org.junit.jupiter.api.Assertions.assertEquals;
import static org.junit.jupiter.api.Assertions.assertTrue;
import java.util.HashSet;
import java.util.Optional;
import java.util.Set;
import org.junit.jupiter.api.Test;

class StepPlannerTest {
    /** Solid floor at y=0 across a wide area; everything else air. */
    private static Passability floorWorld(Set<StepPlanner.Cell> extraSolids) {
        return (x, y, z) -> y > 0 && !extraSolids.contains(new StepPlanner.Cell(x, y, z));
    }
    private final StepPlanner planner = new StepPlanner(1, 3, 24, true);

    @Test void stepsTowardVictimOnFlatGround() {
        Optional<StepPlanner.Cell> n = planner.next(
                new StepPlanner.Cell(0, 1, 0), new StepPlanner.Cell(5, 1, 0), floorWorld(Set.of()));
        assertEquals(Optional.of(new StepPlanner.Cell(1, 1, 0)), n);
    }

    @Test void climbsAWallTooTallToStepOver() {
        // wall of solids at x=1, y=1..5
        Set<StepPlanner.Cell> wall = new HashSet<>();
        for (int y = 1; y <= 5; y++) wall.add(new StepPlanner.Cell(1, y, 0));
        Optional<StepPlanner.Cell> n = planner.next(
                new StepPlanner.Cell(0, 1, 0), new StepPlanner.Cell(5, 1, 0), floorWorld(wall));
        assertTrue(n.isPresent());
        // first move of a climb is upward along the wall face, not into the wall
        assertEquals(new StepPlanner.Cell(0, 2, 0), n.get());
    }

    @Test void fullyWalledInWaits() {
        Set<StepPlanner.Cell> box = new HashSet<>();
        box.add(new StepPlanner.Cell(1, 1, 0));
        box.add(new StepPlanner.Cell(-1, 1, 0));
        box.add(new StepPlanner.Cell(0, 1, 1));
        box.add(new StepPlanner.Cell(0, 1, -1));
        box.add(new StepPlanner.Cell(0, 2, 0)); // ceiling too
        Optional<StepPlanner.Cell> n = planner.next(
                new StepPlanner.Cell(0, 1, 0), new StepPlanner.Cell(5, 1, 0), floorWorld(box));
        assertEquals(Optional.empty(), n);
    }

    @Test void neverReturnsSolidCell() {
        Set<StepPlanner.Cell> wall = Set.of(new StepPlanner.Cell(1, 1, 0));
        Optional<StepPlanner.Cell> n = planner.next(
                new StepPlanner.Cell(0, 1, 0), new StepPlanner.Cell(5, 1, 0), floorWorld(wall));
        n.ifPresent(cell -> assertTrue(floorWorld(wall).isPassable(cell.x(), cell.y(), cell.z())));
    }
}
```
